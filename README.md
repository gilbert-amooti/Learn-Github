# Learn-Github

This repository is going to act as my journal, documenting my Git and Github journey. The concepts that I will be learning may or may not relate to some of you. But whether you are an absolute beginner or a pro and you are going through this, I hope that you find something that will actually help you in your workflow.

I will be pushing each event that I complete and the short notes on what I learned and how I used it specifically in my developer workflow.
## My Git & GitHub Journey

I remember when I was starting out, I was pretty new to everything. This was almost a year ago when I joined university for my Computer Science degree. And I remember before I ever did anything, before even my first class, the lecturer sent a message that instructed us to make sure that we had some tools installed on our machines and git was one of them.
I am sure you can imagine that I was thinking right at that moment. Yes, I asked my self that same question "What is git" and "How do I even install it?". But I taught myself into the basics to get my by.
Now the main purpose for this repository and this journey is to add on those skills that I learned during that time and be able to add some advanced and pretty useful features to it so that I make my work as a software engineer much much easier.

If you are pretty new to git and github in general, there are several resources that you can take use of to get you up to speed.
There are a few resources that I would recommend to get you started:
[Watch the Github for beginners on Youtube](https://www.youtube.com/playlist?list=PL0lo9MOBetEFcp4SCWinBdpml9B2U25-f) is one of my favourite resources and one that helped me out a lot. It is a playlist by on the Github official account on youtube and it will teach you everything that you need to know to get started with github. Check it out.
